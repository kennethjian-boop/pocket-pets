# PET_CATCH_GAME_PROTOTYPE_NOTES

## Purpose
This mini game should feel:
- cozy
- relaxing
- playful
- emotionally safe
- satisfying
- easy for young children

The game is designed primarily for:
- phones
- iPads
- short 1-minute play sessions

It should NOT feel:
- stressful
- hyper competitive
- difficult
- visually cluttered
- arcade-chaotic

---

# Gameplay Feel

## Early Game
The first 30 seconds should feel:
- slow
- manageable
- welcoming
- confidence-building

Fewer items should spawn initially.

Children should immediately understand:
“move and catch.”

---

## Mid Game
31–45 seconds:
- slightly more active
- more engaging
- still readable on mobile

---

## End Game
45–60 seconds:
- exciting
- more chaotic
- rewarding
- satisfying finish

But still:
- readable
- controllable
- not overwhelming

---

# Controls

Controls must feel:
- responsive
- smooth
- forgiving

Children mainly play on:
- touch screen
- iPad
- phone

Large touch controls are important.

---

# Avatar Feel

The equipped pet/skin is emotionally important.

The pet should:
- bounce slightly
- feel alive
- feel cute
- feel like “their character”

Avoid:
- stiff movement
- robotic feel

---

# Item Design

Positive items:
- colorful
- exciting
- easy to identify

Rainbow (+5):
- should feel special
- larger than normal items
- visually noticeable

Bomb:
- visually obvious
- immediately understandable
- playful, not scary

Bomb feedback should be:
- tiny shake
- brief red flash
- “oops” feeling

NOT:
- explosions
- loud punishment
- fail state
- death animation

---

# Visual Style

The game should feel:
- soft
- pastel
- rounded
- cozy
- child-friendly

Avoid:
- dark UI
- sharp aggressive effects
- excessive particles
- too many simultaneous items

---

# Screen Layout

Mobile-first design.

Important:
- avatar should not be too large
- player needs movement space
- game area should feel open
- UI should not block gameplay

---

# Score Feel

Children should frequently gain points.

The game should feel rewarding.

Bombs provide mild challenge only.

The emotional focus is:
“try to beat your previous score.”

NOT:
“fear failure.”

---

# Prototype Direction

The existing prototype feel is GOOD.

Implementation should preserve:
- movement feel
- pacing
- cozy atmosphere
- score popups
- bomb feedback
- spawn progression
- mobile friendliness

Do not redesign the game from scratch.
